# framenote

렌더된 영상에 **프레임 단위로 메모**를 남기고, 그 메모를 코딩 에이전트가 바로 받는다.

```bash
npx framenote out/final.mp4
```

브라우저 창이 하나 열린다. 영상을 보다가 화면을 끌면 그 자리의 **프레임 구간·좌표·렌더본**이
메모에 자동으로 붙는다. 사람이 채우는 칸은 "무엇이"와 "어떻게" 둘뿐이다.
"에이전트에게 보내기"를 누르면 감시 중인 에이전트가 알림을 받아 소스를 고치고 다시 렌더하며,
**같은 창에서** 새 영상으로 교체된다.

## 지키는 것

- **의존 없음** — feedback-kit 을 import 하지 않는다. 코드는 참고만 한다
  (`~/Downloads/feedback-kit`). 서버 전송이 없어서 큐·재시도·진단이 필요 없다.
- **파일이 원본** — 메모의 단일 원천은 `.framenote/` 안의 파일이다. 서버가 죽어도 메모가 남고,
  에이전트는 서버 없이 파일만 읽어도 일할 수 있다.
- **이미지는 파일로** — 첨부는 파일로 저장하고 메모에는 경로만 적는다. 메모에 그림을 박으면
  에이전트가 한 번에 읽을 수 있는 양을 그림이 다 차지한다.
- **밖으로 안 나간다** — 나가는 요청이 한 건도 없다. 수집 서버·트리아지 연동을 넣지 않는다.
- **틀린 프레임을 만들지 않는다** — 프레임을 확정할 수 없으면 메모 작성을 막는다.
  브라우저의 재생 시각 계산은 프레임이 어긋난다.
